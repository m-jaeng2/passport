# Task 03: 동작 인식

## 목표

랜드마크 데이터를 실제 게임 입력으로 사용할 수 있는 안정적인 동작 판정으로 변환한다.

## 범위

- 기본 자세
- 왼손 올리기
- 오른손 올리기
- 양손 올리기
- 양손 모으기
- 입력 잠금 및 재입력 제어

## 체크리스트

- [x] 기본 자세 조건을 정의한다.
- [x] `LeftHandUp` 판정을 구현한다.
- [x] `RightHandUp` 판정을 구현한다.
- [x] `BothHandsUp` 판정을 구현한다.
- [x] `HandsTogether` 판정을 구현한다.
- [x] 1회 입력 잠금 로직을 추가한다.
- [x] 다음 입력 전에 기본 자세 복귀를 요구한다.
- [x] 점프와 일시정지 동작에 재사용 대기시간을 둔다.

## 산출물

- 동작 상태 Enum과 판정 파이프라인
- 반복 사용 가능한 자세 기준값
- 현재 인식 동작을 확인할 수 있는 디버그 출력

## Inspector 메모

- 어깨 기준 높이 임계값
- 손목 간 거리 임계값
- 일시정지 홀드 시간
- 각 동작 재사용 대기시간

## 테스트 체크리스트

- [ ] 하나의 제스처가 하나의 입력 이벤트만 발생시킨다.
- [ ] 손을 든 채 유지해도 입력이 연속 발생하지 않는다.
- [ ] 반대 손의 움직임이 잘못된 입력으로 판정되지 않는다.
- [ ] 점프는 머리 위로 완전히 뻗지 않아도 인식된다.
- [ ] 일시정지는 홀드 시간이 지난 뒤에만 작동한다.

## 기준값 조정 메모

- 손 올리기 높이 기준: 추후 확정
- 바깥쪽 이동 거리 기준: 추후 확정
- 양손 모으기 유지 시간: 0.7초
- 일시정지 입력 잠금 시간: 1초

## 미해결 이슈

- 팔 위치 비대칭으로 인한 오인식 가능성
- 한쪽 손목이 잠시 사라질 때의 처리 방식
- 상체 기울기에 따른 동적 임계값 보정 여부

## 진행 기록

- 상태: 진행 중
- 담당: 메인 에이전트 / 필요 시 서브에이전트 분담
- 메모: `MotionGesture`, `MotionRecognitionManager`, `Task03MotionRecognitionBuilder`를 추가했다. `MotionManager`는 이제 `PoseDetectionManager`의 랜드마크를 받아 기본 자세, 왼손 들기, 오른손 들기, 양손 들기, 양손 모으기를 판정한다. 한 번 제스처가 발동하면 기본 자세로 돌아오기 전까지 입력을 잠그고, 좌우 제스처/점프/일시정지 성격의 동작에 각각 재사용 대기시간을 둔다. `Camera UI`에는 `Gesture Status Text`가 추가되어 현재 제스처와 잠금 상태를 바로 확인할 수 있다.
