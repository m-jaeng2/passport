# Task 01: 게임씬 기초 구성

## 목표

첫 번째 프로토타입을 위한 단일 `Game Scene`의 기초 구조를 만든다.

## 범위

- 씬 구조
- 월드 배치
- 레인 기준점
- 카메라 추적 기본값
- 임시 도착 지점

## 체크리스트

- [x] 단일 메인 `Game Scene`을 생성하거나 기존 씬을 기준 씬으로 확정한다.
- [x] `Environment`, `Character`, `Managers`, `Canvas` 루트 구조를 정의한다.
- [x] 왼쪽, 가운데, 오른쪽 3개 레인 기준점을 배치한다.
- [x] 임시 랜드마크와 `Finish Trigger`를 배치한다.
- [x] 전진 방향과 월드 스케일 기준을 정한다.
- [x] 기본 3인칭 추적 카메라 구성을 만든다.
- [x] Inspector에서 연결해야 할 참조 항목을 문서화한다.

## 산출물

- 프로토타입용 안정적인 씬 계층 구조
- 명확한 레인 기준점
- 시작 지점부터 도착 지점까지 테스트 가능한 월드 경로

## Inspector 메모

- 레인 기준 Transform
- `Finish Trigger` Collider
- 카메라 추적 대상
- 캐릭터 시작 위치

## 테스트 체크리스트

- [ ] 씬을 열었을 때 누락된 참조가 없다.
- [ ] 캐릭터 시작 위치가 가운데 레인이다.
- [ ] 레인 기준점이 보이는 도로 위치와 일치한다.
- [ ] `Finish Trigger`까지 실제로 도달 가능하다.
- [ ] 카메라가 올바른 전진 방향을 바라본다.

## 열린 이슈

- 첫 플레이 버전에 필요한 정확한 도로 길이
- 임시 아트를 Primitive로 둘지, 초기부터 일부 에셋을 넣을지 여부

## 진행 기록

- 상태: 완료
- 담당: 메인 에이전트 / 필요 시 서브에이전트 분담
- 메모: `Task01SceneBuilder`, `ThirdPersonFollowCamera`, `SceneFoundationReferences` 스크립트를 추가했고, 배치 실행으로 `SampleScene`에 `Environment`, `Character`, `Managers`, `Canvas`, 레인 기준점, 임시 도착 지점, `Finish Trigger`, 카메라 추적 기준점을 반영했다.
