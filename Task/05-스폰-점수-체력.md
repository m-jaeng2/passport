# Task 05: 스폰 점수 체력

## 목표

장애물, 아이템, 점수, 콤보, 체력 시스템을 연결해 핵심 게임성을 만든다.

## 범위

- 장애물 스폰
- 아이템 스폰
- 충돌 처리
- 점수
- 콤보
- 체력
- 정리 및 풀링

## 체크리스트

- [x] 레인 기반 장애물 스폰 규칙을 만든다.
- [x] 레인 기반 아이템 스폰 규칙을 만든다.
- [x] 회피 불가능한 배치를 방지한다.
- [x] `Fence`, `Pedestrian`, `Barrier`, `RedSignalZone`를 구현한다.
- [x] `Heart`, `Snack`, `GoldenPassport`를 구현한다.
- [x] 장애물 피해량과 아이템 효과를 정확히 반영한다.
- [x] 점수, 콤보, 체력 계산을 연결한다.
- [x] 지나간 오브젝트를 제거하거나 재사용한다.
- [x] 반복 생성 오브젝트용 풀링 구조를 추가한다.

## 산출물

- 안전한 생성 규칙을 가진 Spawn 시스템
- 장애물 및 아이템 동작 구현
- 점수, 콤보, 체력이 연결된 게임플레이 루프

## Inspector 메모

- 생성 간격 범위
- 캐릭터 앞쪽 생성 거리
- 캐릭터 뒤쪽 정리 거리
- 장애물 및 아이템 데이터 에셋

## 테스트 체크리스트

- [ ] 장애물이 유효한 레인에만 생성된다.
- [ ] 항상 최소 한 개의 회피 가능한 경로가 존재한다.
- [ ] 아이템 획득 효과가 정확히 적용된다.
- [ ] 피해량이 기획 수치와 일치한다.
- [ ] 콤보가 의도한 규칙대로 증가하고 초기화된다.
- [ ] 지나간 오브젝트가 정상적으로 정리된다.

## 밸런싱 메모

- 첫 장애물 생성 지연: 5초
- 기본 플레이 목표 시간: 약 60초
- 황금 여권 생성 빈도: 매우 낮음

## 미해결 이슈

- 게임 진행에 따른 생성 속도 곡선
- `Perfect / Good / Miss` 판정 체계를 이 단계에서 넣을지 후속 단계로 미룰지

## 진행 기록

- 상태: 진행 중
- 담당: 메인 에이전트 / 필요 시 서브에이전트 분담
- 메모: `SpawnManager`가 항상 한 개 이상의 안전 레인을 남기는 웨이브 기반 생성 규칙을 사용한다. 장애물은 통과 시 콤보와 회피 점수를 주고, 충돌 시 `CollisionManager`가 `HealthManager`, `ScoreManager`와 연결되어 피해, 회복, 점수, 콤보 초기화를 처리한다. `GameplayHudReferences`로 점수, 콤보, 체력, 생성 상태를 `Gameplay UI`에 표시하고, 반복 생성 오브젝트는 타입별 풀로 재사용한다.
