# Task 04: 캐릭터 러너 코어

## 목표

동작 입력을 실제 3레인 자동 전진 캐릭터 조작으로 연결한다.

## 범위

- 전진 이동
- 레인 변경
- 점프
- 추적 카메라
- 일시정지 연동

## 체크리스트

- [ ] 월드 `Z`축 방향으로 일정한 자동 전진을 구현한다.
- [ ] 3개 레인 위치를 정의한다.
- [ ] 왼쪽과 오른쪽으로 한 레인씩 이동시킨다.
- [ ] 레인 범위를 벗어나지 않도록 제한한다.
- [ ] 점프와 짧은 재사용 대기시간을 구현한다.
- [ ] 레인 이동과 점프 중에도 전진이 유지되도록 한다.
- [ ] 일시정지와 종료 상태에서 이동을 멈춘다.
- [ ] 메인 카메라가 캐릭터를 부드럽게 따라가도록 만든다.

## 산출물

- 플레이 가능한 러너 이동 코어
- 캐릭터 추적 카메라
- 동작 입력과 캐릭터 행동의 연결 구조

## Inspector 메모

- 전진 속도
- 레인 간격
- 레인 변경 시간
- 점프 높이와 점프 시간
- 카메라 오프셋과 보간 값

## 테스트 체크리스트

- [ ] 캐릭터가 가운데 레인에서 시작한다.
- [ ] 좌우 입력이 정확히 한 레인씩만 이동시킨다.
- [ ] 캐릭터가 3레인 범위를 벗어나지 않는다.
- [ ] 점프가 낮은 장애물을 넘을 수 있는 형태로 동작한다.
- [ ] 일시정지 시 이동이 깨지지 않고 정지한다.
- [ ] 점프와 레인 이동 중에도 카메라 시야가 안정적이다.

## 열린 이슈

- 이동 구현을 Transform 보간, Character Controller, Rigidbody 중 무엇으로 할지
- 최종 캐릭터가 들어오기 전 임시 애니메이션 처리 방식

## 진행 기록

- 상태: 시작 전
- 담당: 메인 에이전트 / 필요 시 서브에이전트 분담
