# Task 06: 게임흐름 UI 결과

## 목표

자세 확인부터 결과 패널까지 전체 플레이 루프를 마무리한다.

## 범위

- 시작 안내
- 준비 확인
- 카운트다운
- 타이머
- 일시정지
- 카메라 인식 실패 처리
- 결과 패널
- 최고 점수 저장

## 체크리스트

- [ ] 시작 전 자세 안내 흐름을 만든다.
- [ ] 인식 준비 완료 상태를 확인한 뒤 시작한다.
- [ ] 시작 확인과 자동 시작 보조 흐름을 구현한다.
- [ ] 카운트다운과 게임 상태 전환을 구현한다.
- [ ] 점수, 최고 점수, 타이머, 콤보, 판정 문구를 표시한다.
- [ ] 양손 모으기 동작으로 일시정지와 재개를 구현한다.
- [ ] 짧은 실패, 중간 실패, 장시간 실패에 대한 카메라 대응을 구현한다.
- [ ] 성공, 체력 부족, 시간 초과, 장시간 인식 실패에 따라 게임을 종료한다.
- [ ] 같은 `Game Scene` 안에 결과 패널을 표시한다.
- [ ] `PlayerPrefs`로 최고 점수를 저장하고 다시 불러온다.

## 산출물

- 하나의 씬에서 완결되는 플레이 루프
- 게임플레이, 카메라 상태, 일시정지, 결과용 UI
- 성공과 실패 처리가 연결된 종료 흐름

## Inspector 메모

- UI 텍스트 참조
- 카운트다운 시간
- 매치 타이머 값
- 카메라 실패 임계값
- 결과 패널 버튼 연결

## 테스트 체크리스트

- [ ] 필요한 랜드마크가 안정적으로 보일 때만 준비 완료가 된다.
- [ ] 게임 시작 전 카운트다운이 표시된다.
- [ ] 일시정지와 재개가 정상적인 플레이 상태로 이어진다.
- [ ] 카메라 인식 실패 경고가 단계적으로 올라간다.
- [ ] 결과 패널이 올바른 결과와 점수를 보여준다.
- [ ] 다시 하기가 정상적으로 재시작된다.
- [ ] 최고 점수가 세션 사이에서 유지된다.

## 실패 기준 메모

- 준비 완료 유지 시간: 2초
- 짧은 경고 기준: 1초 미만
- 자동 일시정지 기준: 약 3초
- 강제 종료 기준: 약 15초
- 최대 제한 시간: 70초에서 90초

## 진행 기록

- 상태: 시작 전
- 담당: 메인 에이전트 / 필요 시 서브에이전트 분담
