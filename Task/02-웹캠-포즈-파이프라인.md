# Task 02: 웹캠 포즈 파이프라인

## 목표

웹캠 입력을 연결하고 게임플레이에 필요한 신체 랜드마크를 제공한다.

## 범위

- 웹캠 연결
- 미리보기 렌더링
- 포즈 랜드마크 수집
- 인식 상태 전달

## 체크리스트

- [ ] 웹캠을 안전하게 시작하고 종료한다.
- [ ] 카메라 UI 영역에 웹캠 영상을 출력한다.
- [ ] 좌우 반전과 미리보기 방향을 올바르게 처리한다.
- [ ] 얼굴 중심 또는 코, 양쪽 어깨, 양쪽 손목을 수집한다.
- [ ] 게임 로직에서 사용할 정규화 좌표를 노출한다.
- [ ] 신뢰도와 인식 준비 상태를 전달한다.
- [ ] 카메라 없음 또는 입력 불가 상태를 명확히 처리한다.

## 산출물

- Unity 안에서 동작하는 웹캠 미리보기
- 핵심 관절의 안정적인 랜드마크 데이터
- 게임 시스템에서 사용할 수 있는 인식 상태 정보

## Inspector 메모

- 카메라 장치 선택
- 미리보기 텍스처 연결 대상
- 포즈 파이프라인 컴포넌트 참조

## 테스트 체크리스트

- [ ] 플레이 모드에서 웹캠 영상이 보인다.
- [ ] 좌우 랜드마크가 일관되게 매핑된다.
- [ ] 얼굴, 어깨, 손목 정보가 실시간으로 갱신된다.
- [ ] 일시적인 카메라 연결 끊김을 정상 처리한다.
- [ ] 앉은 자세 기준 거리에서 미리보기가 안정적으로 동작한다.

## 기준값 메모

- 랜드마크 최소 신뢰도: 추후 확정
- 준비 완료 판정 시간: 2초
- 짧은 카메라 경고 기준: 1초 미만
- 자동 일시정지 기준: 약 3초

## 열린 이슈

- Unity 안에서 MediaPipe를 어떤 방식으로 연결할지
- 좌표 보정과 스무딩을 공급 계층에서 할지 게임 계층에서 할지

## 진행 기록

- 상태: 시작 전
- 담당: 메인 에이전트 / 필요 시 서브에이전트 분담
