# 역할
너는 20년차 유니티 게임 프로그래머이자, UI/UX에 능통한 미적감각이 뛰어난 디자이너야.

# 목표
노인과 장애인을 위한 모션 운동 게임 만들기. mediapipe를 유니티 환경과 연결해서 동작을 인식하고 그걸 게임 환경에 반영해서 진행하는 게임을 만들거야. 
게임 컨셉은 여행이야. 참고한 게임 자료는 'Subway Surfer'라는 게임이니까 참고부탁해.

# 요구사항 
'Plan/1차 프로젝트 기획서'를 참고해서 AGENTS.md 파일과 Task를 단계별로 파일 만들어줘.
각 Task에는 체크리스트를 포함해서 계속해서 진행 상황이 업데이트 될 수 있도록 만들어줘. 

기획서 자체에 내용이 많아. 내가 중간중간 수정한 부분들이 있는데, 숫자나 순서 안맞는건 맞춰주고 중복되는 내용은 삭제해서 너가 작업하기 쉬운 파일로 수정해도 돼.
# 서브에이전트 작업 규칙

이 문서는 이 저장소에서 서브에이전트가 작업할 때 따라야 할 기준을 정리한다.

## 프로젝트 범위

- 실제 Unity 프로젝트 루트는 `PassportUnity/`이다.
- 주요 추적 대상은 `PassportUnity/Assets`, `PassportUnity/Packages`, `PassportUnity/ProjectSettings`이다.
- 현재 프로젝트는 아직 기본 Unity URP 템플릿에 가까우므로 변경은 작고 의도적으로 유지한다.

## 작업 시작 전

- 먼저 작업 요청을 읽고 변경 범위를 최대한 작게 유지한다.
- 수정 대상이 소스 파일인지 생성 파일인지 먼저 확인한다.
- 작업과 무관한 사용자 변경은 건드리지 않는다.

## 추적할 파일

- 다음 경로의 소스 및 설정 변경을 추적한다.
- `PassportUnity/Assets`
- `PassportUnity/Packages/manifest.json`
- `PassportUnity/Packages/packages-lock.json`
- `PassportUnity/ProjectSettings`
- `README.md`
- `mds/`
- `Task/`
- `agent.md`

## 피해야 할 파일

- 다음과 같은 Unity 생성 폴더는 커밋하지 않는다.
- `PassportUnity/Library`
- `PassportUnity/Temp`
- `PassportUnity/Logs`
- `PassportUnity/UserSettings`
- 다음과 같은 IDE 자동 생성 파일에 의존하지 않는다.
- `*.csproj`
- `*.sln`
- `*.slnx`

## 커밋 규칙

- 의미 있는 변경 단위마다 하나의 커밋 메시지를 사용한다.
- 커밋 메시지는 짧은 현재형 문장으로 작성한다.
- 시작 접두사는 아래 중 하나를 사용한다.
- `feat:`
- `fix:`
- `chore:`
- `docs:`

## 기록 규칙

- 의미 있는 변경이 생기면 `agent.md`에 짧은 기록을 추가한다.
- 각 기록에는 아래 항목이 포함되어야 한다.
- 변경 요약
- 커밋 메시지
- 변경 파일
- 메모

## 현재 시작 지점

- 현재 주요 씬은 `PassportUnity/Assets/Scenes/SampleScene.unity` 하나다.
- 대부분의 현재 에셋은 템플릿 에셋이다.
- 실제 게임플레이 작업이 시작되면 필요한 시점에 맞춰 `Assets` 아래에 `Scripts`, `Prefabs`, `UI`, `Art` 같은 폴더를 만든다.
