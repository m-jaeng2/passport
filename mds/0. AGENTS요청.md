# 역할
너는 20년차 유니티 게임 프로그래머이자, UI/UX에 능통한 미적감각이 뛰어난 디자이너야.

# 목표
노인과 장애인을 위한 모션 운동 게임 만들기. mediapipe를 유니티 환경과 연결해서 동작을 인식하고 그걸 게임 환경에 반영해서 진행하는 게임을 만들거야. 
게임 컨셉은 여행이야. 참고한 게임 자료는 'Subway Surfer'라는 게임이니까 참고부탁해.

# 요구사항 
'Plan/1차 프로젝트 기획서'를 참고해서 AGENTS.md 파일과 Task를 단계별로 파일 만들어줘.
각 Task에는 체크리스트를 포함해서 계속해서 진행 상황이 업데이트 될 수 있도록 만들어줘. 

기획서 자체에 내용이 많아. 내가 중간중간 수정한 부분들이 있는데, 숫자나 순서 안맞는건 맞춰주고 중복되는 내용은 삭제해서 너가 작업하기 쉬운 파일로 수정해도 돼.
# Sub-Agent Working Rules

This file defines how sub-agents should work in this repository.

## Project Scope

- The real Unity project root is `PassportUnity/`.
- The main tracked areas are `PassportUnity/Assets`, `PassportUnity/Packages`, and `PassportUnity/ProjectSettings`.
- The current project is still close to the default Unity URP template state, so changes should stay focused and intentional.

## Before Starting Work

- Read the task request first and keep the change scope as small as possible.
- Check whether the target files are source files or generated files before editing.
- Do not touch unrelated user changes.

## Files To Track

- Track source and config changes in:
- `PassportUnity/Assets`
- `PassportUnity/Packages/manifest.json`
- `PassportUnity/Packages/packages-lock.json`
- `PassportUnity/ProjectSettings`
- `README.md`
- `mds/`
- `agent.md`

## Files To Avoid

- Do not commit generated Unity folders such as:
- `PassportUnity/Library`
- `PassportUnity/Temp`
- `PassportUnity/Logs`
- `PassportUnity/UserSettings`
- Do not rely on generated solution or project files such as:
- `*.csproj`
- `*.sln`
- `*.slnx`

## Commit Rules

- Write one commit message per meaningful change unit.
- Use short present-tense messages.
- Start commit messages with one of:
- `feat:`
- `fix:`
- `chore:`
- `docs:`

## Logging Rules

- For each meaningful change, append a short entry to `agent.md`.
- Each entry should include:
- Summary
- Commit message
- Changed files
- Notes

## Current Starting Point

- `PassportUnity/Assets/Scenes/SampleScene.unity` is the only main scene currently visible.
- Most current assets are still template assets.
- If new gameplay work starts, prefer creating clear folders under `Assets` such as `Scripts`, `Prefabs`, `UI`, and `Art` only when they are needed.
